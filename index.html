设置与启停

正常采集无需串口指令

串口格式8 数据位 · 无校验 · 1 停止位
硬件流控无
数据方式二进制 · 连续主动输出
  1. 完成五线连接，设置串口为 115200 / 8N1。
  2. 待机时短按一次按钮，启动采集；采集中短按一次，停止采集。
  3. 每次操作后松开按钮，等待状态变化，再进行下一次操作。

长按只触发一次；上电时若已按住，须先松开。停止采集后无采样数据输出；仅凭“无数据”不能区分待机与连接异常。

03

数据帧与接收规则

16 位原码 · CRC5 校验
B00x80 | (ADC & 0x7F)
B1(ADC >> 7) & 0x7F
B2(CRC5(ADC) << 2) | ((ADC >> 14) & 0x03)
示例 · 按此顺序接收
E00B5E

ADC = 0x85E0　CRC5 = 0x17

ADC 重建公式ADC = (B0 & 0x7F) | ((B1 & 0x7F) << 7) | ((B2 & 0x03) << 14)

ADC 为 16 位无符号原码。每帧按 B0 → B1 → B2 发送，不附加逗号、换行或文本帧头。不能将 B0/B1 直接转换为小端 uint16；UART 字节内仍为硬件 LSB-first。

CRC5 约定：宽度 5，多项式 x⁵+x²+1（0x05），初值 0x1F，输入/输出不反射，最终异或 0x00，不额外补零。仅对 ADC 原码计算：先低字节、再高字节，每字节按 bit7 → bit0 处理。不含帧标记位，亦非 CRC-5/USB。

  1. 任何时候收到 bit7 = 1 的字节，都将其作为新 B0，并丢弃未完成的旧帧。
  2. 未收到 B0 时忽略 bit7 = 0 的字节；收到 B0 后，依次接收两个 bit7 = 0 的字节。
  3. 收齐 3 字节后重建 ADC。仅当计算的 CRC5 等于 (B2 >> 2) & 0x1F 时更新数值，随后等待下一 B0。
  4. 解析状态须跨读取保留。串口错误、Break、溢出或重开时清空状态；溢出时同时丢弃完整性不确定的缓冲数据。

本数据流只提供 ADC 原码。帧中不含序号，无法据此识别整帧丢失或重复；CRC5 也不能检出所有多位错误。

开发参考：CRC5 与逐字节解析（C）
每收到一个字节调用一次；串口异常时调用 rx_reset。
#include <stdint.h>
#include <stdbool.h>

typedef struct {
    uint8_t b0, b1, step;
} rx_state;

static uint8_t crc5_adc(uint16_t adc)
{
    uint8_t crc = 0x1F;
    for (unsigned n = 0; n < 2; ++n) {
        uint8_t value = (uint8_t)(adc >> (n * 8));
        for (int bit = 7; bit >= 0; --bit) {
            uint8_t feedback = ((crc >> 4) ^ (value >> bit)) & 1;
            crc = (uint8_t)((crc << 1) & 0x1F);
            if (feedback) crc ^= 0x05;
        }
    }
    return crc;
}

static void rx_reset(rx_state *s)
{
    s->step = 0;
}

/* Keep s across reads. Only true means a new, CRC-valid ADC value. */
static bool rx_byte(rx_state *s, uint8_t byte, uint16_t *adc)
{
    if (byte & 0x80) {
        s->b0 = byte;
        s->step = 1;
    } else if (s->step == 1) {
        s->b1 = byte;
        s->step = 2;
    } else if (s->step == 2) {
        uint16_t value = (uint16_t)((s->b0 & 0x7F) |
                         ((uint16_t)s->b1 << 7) |
                         ((uint16_t)(byte & 0x03) << 14));
        rx_reset(s);
        if (crc5_adc(value) == ((byte >> 2) & 0x1F)) {
            *adc = value;
            return true;
        }
    }
    return false;
}

/* Initialize once: rx_state state = {0};
   Feed every received byte to rx_byte(&state, byte, &adc).
   Reset after serial errors; discard uncertain data after overflow. */
